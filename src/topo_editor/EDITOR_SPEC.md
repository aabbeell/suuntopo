# Suuntopo editor: specification

## Overview

Browser-based visual editor for climbing topos. It writes the one-line `STP1` topo that the Suuntopo watch app (`src/suuntopo_canvas`, v1.0) reads from its "Topo line from editor" setting, and it can also write a built-in topo file (`ext*.js`) for the app package. The project itself is saved as JSON for re-editing.

Files:
- `index.html`: the editor.
- `stp1.js`: the encoder, also loaded by the Node tests.
- `watch.js`: the watch app's renderer and parser, generated by `sync-watch.js`.

There is no build step and no dependency. The format is specified in `docs/suuntopo_canvas/SPEC.md` §4.3; this file covers the editor.

## Tool Categories

### 1. Pitch (route + anchors)
- **Route Line** (R key): Left-click adds waypoints, right-click adds waypoint + anchor. Polyline.
- **Anchor** (A key): Click on route point to toggle as belay station.

### 2. Topo Features (signs)
**Rect-based** (click+drag to set position and size):
Crack, Chimney, Corner, Couloir, Overhang, Roof, Ledge, Slab, Ramp

**Diagonal** (click+drag any angle):
Arete

**Point-based** (click to place):
Bolt, Piton, Rappel, Chockstone, Tree, Grass, Scree, Label

### 3. Rock Contours
- **Contour Line**: Polyline (click points, Enter to finish)
- **Contour Fill**: Polygon (click 3+ points, Enter to close and fill)

### 4. Pitch Info
- **Belays are sorted by their route position, not by click order.** The first belay is the start stance. Belay k ends pitch k and carries pitch k's grade, length, notes and band; the start belay's pitch fields are not exported (a warning says so).
- **Pitch list.** The side panel lists the pitches in route order: the "S" row, then each pitch with its grade, length, notes and band.
- **Band.** The difficulty colour on the watch. "auto" computes it from the grade and the topo's grade system; a fixed band 0-4 overrides it.
- **Topo info.** Name, wall, overall grade, grade system (French, UIAA, YDS, Other), and approach and descent notes (each at most 200 characters, shown on the watch at Start and Top).

## Data Format

**Watch format: STP1** (what "Copy for Suunto app" puts on the clipboard). It is one line, `STP1|N<name>|W<wall>|G<grade>|A<approach>|D<descent>|R<route>|B<belays>|P<band~grade~len~notes>…|F<letter><paths>…`. The full grammar, the limits and the error codes are in `docs/suuntopo_canvas/SPEC.md` §4.3. The encoder (`stp1.js`) does the following:
- **Text.** Normalises to NFC, replaces `|` with `/` and control characters with spaces, and trims. In grades, `~` becomes `-`. A built-in file also replaces `'` with `’` and `\` with `/`. *(Round 2.)* `<` becomes `‹` and `&` becomes `+`: the watch's `setText` reads markup and character entities, so its parser rejects both (E2, E5, E7).
- **Long patterned pieces** *(round 2)*. A crack, roof, overhang or ramp piece longer than 466 units gets a warning: the watch draws a piece longer than two screen widths on the zoomed-in Map as a plain line, which bounds its drawing work (watch SPEC §7).
- **Belays.** `B` holds route vertex indices, sorted by the vertex nearest to each anchor.
- **Feature shapes.**
  - A rect becomes a 2-point line along its long side.
  - A slab rect becomes a closed 4-point outline.
  - An arete is a 2-point line.
  - Contours become paths.
  - Labels are editor-only and are not exported.
- **Grouping.** One `F` record per feature type.
- **Limits** checked against the watch parser:

  | Field | Limit |
  |---|---|
  | name | 1-32 characters |
  | wall | 32 characters |
  | grade | 10 characters |
  | approach, descent, notes | 200 characters each |
  | route points | 2-120 |
  | belays | 2-61 |
  | pitch length | up to 999 m |
  | terrain | at most 40 types, 100 shapes, 400 points |
  | coordinates | 0..4095 |
  | size: the Topo line setting | **1,500 bytes** (UTF-8) |
  | size: a built-in file | **3,500 bytes** |

**Project JSON** (Save project / Load project file / Import project JSON) keeps everything needed to edit again:

```json
{
  "name": "Fictional Demo",
  "wall": "Demo crag",
  "grade": "5c",
  "gradeSystem": "french",
  "approach": "Walk 20 min",
  "descent": "Rappel the route",
  "width": 1000,
  "height": 3000,
  "anchors": [
    { "x": 210, "y": 1440, "grade": "", "length": "", "info": "", "band": "auto" },
    { "x": 205, "y": 1230, "grade": "4c", "length": "25m", "info": "Slab", "band": "auto" }
  ],
  "route": [[150, 1500], [210, 1440], [225, 1330], [205, 1230]],
  "features": [
    { "type": "crack", "x": 251, "y": 723, "w": 9, "h": 120 },
    { "type": "arete", "x1": 100, "y1": 500, "x2": 200, "y2": 300 },
    { "type": "bolt", "x": 235, "y": 1320 },
    { "type": "contour", "points": [[140, 1400], [130, 1300]] }
  ]
}
```

**Feature shapes:**
- Rect: `{type, x, y, w, h}`
- Diagonal: `{type, x1, y1, x2, y2}` (arete)
- Point: `{type, x, y}`; a label also has `text`
- Line: `{type, points[]}` (contour, contour_poly)

## Scaling & Coordinate System

- **1 editor unit = 1 watch pixel**
- Watch display: 466×466 px circular
- Grid: major lines every 466 units (= 1 watch screen), minor every 116 units
- Default canvas: 1000×3000 (adjustable, or set by background image)

## Editor Features

### Selection & Editing
- **Select tool** (S key): Click, shift+click, or marquee drag to multi-select
- Mixed selection: features + route points selected together
- Drag to move all selected items
- Delete/Backspace removes selection
- Arrow keys nudge (1px, Shift+arrow = 10px)
- Ctrl+A selects all
- Double-click label to edit text, double-click anchor to focus grade input

### Canvas
- White/paper background (#f5f5f0) with grid
- Pan: Alt+drag or middle-click
- Zoom: scroll wheel
- Background image with 4-corner perspective transform (drag corners independently)

### Watch Preview
- **The preview is the watch renderer.** `watch.js` holds the watch app's own parser (`ext1.js`, `ext9.js`) and its renderer (the shared block of `t.html`). It is generated by `node src/topo_editor/sync-watch.js`; `--check` reports a stale copy, and test T11 fails on one.
- The preview draws the Map view (the three canvas tiles) at the selected belay, with the watch's own auto-fit, on a 240 px round canvas.
- Under the preview, the editor lists the units used per tile (cap 150) and how many shapes were left out for budget.
- If the topo is not complete yet, it shows the watch error code instead.
- **Viewport overlay mode**: a yellow circle on the canvas shows the watch's visible area and follows the mouse.

### Import/Export
- **Copy for Suunto app:** a modal with the STP1 line, its byte count against the 1,500 B setting limit, and the errors and warnings. Errors block copying. Every export is parsed again with the watch parser (round trip); a mismatch blocks copying.
- **Download topo .txt:** the same line as a file.
- **Download built-in file (ext.js):** a watch app built-in topo file, one function returning the line, checked against 3,500 B. Save it as `ext5.js`-`ext7.js` in `src/suuntopo_canvas` to swap a built-in, and update the card index (name~grade~pitches) in `ext3.js`; test T5 checks the two agree.
- **On the watch: how to and FAQ:** a modal with the user guide for the watch app: loading a topo (use the editor on a computer, send the line to the phone, paste it into "Topo line from editor", sync; it shows up at the next exercise start), the long-press buttons, the button lock (and unlocking from another display), back to Start, "Loading NN%", the Map and grade colours, units, the example topos, what is logged, and error codes E1-E9 with what to do. It is the FAQ the store text links to once the editor is hosted.
- **Save project (JSON), Load project file, Import project JSON:** the editable project.
- **Load Background Image:** with perspective corner handles.
- The byte counter in the status bar shows "Topo: N / 1500 B".

### Undo/Redo
- Ctrl+Z / Ctrl+Shift+Z (or Ctrl+Y)
- 50-level undo stack
- Unsaved changes warning on tab close

### Keyboard Shortcuts

## Watch App Compatibility

The watch app is Suuntopo v1.0 (`src/suuntopo_canvas`). What it draws:
- **The route.** The current pitch in yellow, upcoming pitches red, climbed pitches dark red, approach and descent grey. Belays are white dots, and the target belay is ringed yellow.
- **Line features:** roof, overhang, ledge, crack, chimney, corner, arete, ramp, couloir, slab, contour. Decorations (teeth, zig-zag, hatch) appear only when zoomed in.
- **Point features:** bolt, piton, rappel, chockstone, tree, grass, scree. They appear only when zoomed in.
- **Contour fill** is exported but not drawn. Labels are not exported.
- **The budget.** Each of the three canvas tiles has a 150-unit cap. Terrain that does not fit is left out, lowest priority first, and the route always stays.

### Watch Screens
- **Topo list:** name, label ("Not a real climb" or "Schematic topo" for built-ins), the whole open topo, "grade  n P", and the card position.
- **Map:** name at the top, the current pitch's "grade  length" in its band colour, and "Pitch k/n", "Start" or "Top".
- **Info:** name, "P k  grade  length", the notes word-wrapped in pages of 6 lines, and "k/n (page/pages)".
